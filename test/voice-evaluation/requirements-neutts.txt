# NeuTTS Air's extras, kept apart from requirements-gguf.txt on purpose.
#
# WHY A SECOND FILE. `neucodec` pulls in `torchtune`, which pulls in `torchao`,
# and that chain is the least stable thing this benchmark touches. When it was
# in the shared file its failure took the Orpheus arm down with it - that arm
# then started, found no `snac`, and reported a model failure that was really a
# packaging failure two steps earlier. One model's dependency swamp must not be
# able to sink another model's reading.
#
# THE PIN IS THE WHOLE FIX, AND THE WINDOW IS TWO RELEASES WIDE.
#
# Measured 2026-09-14. `neucodec` requires `torchao>=0.12.0` at every version it
# has ever published. It also imports `torchtune`, whose code does
# `from torchao.dtypes.nf4tensor import NF4Tensor` - and that module exists in
# torchao 0.12.0 and 0.13.0 and was REMOVED in 0.14.0.
#
#   torchao 0.11.0   below neucodec's floor      -> pip: ResolutionImpossible
#   torchao 0.12-13  satisfies both              -> works
#   torchao 0.14+    torchtune's import is gone  -> ModuleNotFoundError
#
# So the satisfiable window is exactly two releases and an unpinned install
# lands above it. torchtune is archived upstream, so this will not self-heal.
torchao==0.13.0
neucodec>=0.0.6

# The runtime itself, from git because it is not published to PyPI.
neutts @ git+https://github.com/neuphonic/neutts-air.git
